# NIKRION Operational Intelligence Design System

This UI layer is intentionally customized for NIKRION DealerOS and avoids generic admin-template patterns.

Core idea:
- Command workspace, not dashboard template
- Workflow-based navigation, not flat sidebar
- Role-aware operational UX
- Human business process layout
- Premium industrial intelligence visual identity

Primary navigation language:
- Command
- Customer Flow
- Field Ops
- Vehicle Grid
- Organization
- Reports

This creates product identity around real dealership operations rather than common CRM admin UI.
