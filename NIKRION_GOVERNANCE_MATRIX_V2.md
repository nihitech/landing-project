# NIKRION Governance Matrix v2

This is the human-management authority model.

Core principle:
- Sales users work only on own operational tasks.
- Managers control team operations, not organization/master data.
- BM controls branch operations.
- DGM controls multi-branch/regional operations.
- GM controls business operations.
- MD/CEO control enterprise strategy.
- Admin controls system configuration, not business decisions automatically.

This layer is the decision map. Future patches should apply these rules to:
- leads route
- vehicles route
- stock route
- reports route
- dashboards
- approval workflows
